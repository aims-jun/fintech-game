# AIMS Paper Race 5.7 — 한국 영수증 사진과 서식 출처

확인일: 2026-11-22. 게임 안의 사람, 기관, 날짜, 금액과 등록번호는 가상입니다. 영수증은 아래 국내 발급 예시를 바탕으로 편집한 전시용 이미지입니다.

## 병원 영수증 사진

- 공개 페이지: [인스마스터 — 장염 수액 처방 청구 사례](https://insmaster.co.kr/site_info/278)
- 사용한 사진: [외래 진료비 계산서·영수증](https://insmaster.co.kr/static/media/board/de/image/2024/1154475294851431.JPG)
- 게임 파일: `assets/receipt-hospital-photo.png`

실제 발급 영수증의 촘촘한 표, 환자정보 띠, 급여·비급여 열과 우측 금액 산정 영역을 바탕으로 사진을 편집했습니다. 원본의 금액, 발급 정보, 흐림 처리 영역과 설명용 빨강·파랑 테두리를 제거했습니다. 고정 인쇄선과 항목명을 남기고 가상 정보가 들어갈 칸을 비웠습니다. 복잡한 항목 번호 수식은 생략했으며, 법정서식의 완전한 복제본은 아닙니다.

게임은 환자명, 날짜, 영수증 번호, 기관명, 수납금 등을 사진 위의 같은 좌표에 표시합니다. 이 값은 정답 판정에 쓰는 데이터와 동일합니다. 급여 본인부담 B와 비급여 N, 수납금 T는 원래 문제의 값을 보존합니다. 함께 나오는 세부내역서가 있으면 실제 문제 항목을 해당 진료비 분류에 배치합니다. 추가한 공단부담 P는 가상 금액이며 실제 수가 계산이 아닙니다. 진료비 총액은 T+P로 표시합니다. 세부 항목이 없는 문제는 기타에 묶습니다.

## 약국 영수증 사진

- 공개 자료: [숭실대학교가 공개한 DB손해보험 보험금 청구 안내 PDF](https://small.ssu.ac.kr/api/resource/download/7584)
- 참고 부분: PDF 13쪽 약국 영수증 예시 이미지의 맨 위 왼쪽, 약 봉투에 인쇄된 `약제비 계산서·영수증` 패널
- 게임 파일: `assets/receipt-pharmacy-photo.png`

실제 약 봉투 사진에서 영수증 표 부분만 골라 세로형 사진으로 편집했습니다. 녹색 제목과 인쇄선, 종이 질감, 환자·조제 정보, 약제비·수납 내역과 발급란을 살렸습니다. 원본의 환자·약국·약사 정보와 금액, 주소, 등록번호, 도장은 제거했습니다. 약 사진이나 복약 안내, 원본의 실제 약품명은 게임에 포함하지 않았습니다.

환자명·조제일·발급일·약국명·영수증 번호와 금액은 가상 데이터로 채웁니다. 약국 영수증에는 환자가 낸 돈과 전체 약제비를 구분해 표시합니다. 병원 진료비를 약국 영수증이라고 이름만 바꾸지 않도록 별도 사진과 별도 배치를 사용합니다.

## 청구서 사진 (5.6)

- 참고 원본: [삼성화재 공개 보험금 청구서, 첫 페이지](https://www.samsungfire.com/download/claim/claim_new.pdf)
- 게임 파일: `assets/claim-form-photo.png` (1055 × 1491)

작성 전의 공식 공개 서식을 직접 확인하고, 인적사항·진료 및 청구·수령 계좌·확인 및 서명 구역을 가진 게임용 사진으로 편집했습니다. 검은 인쇄선과 종이 질감을 사용하고 보험사 로고·QR·긴 법률 문구는 제외했습니다. 실제 발급 문서를 촬영한 원본 사진이라고 표시하지 않습니다.

환자 이름·날짜·진료 구분·기관은 게임 데이터입니다. 5.7의 신규 문제는 청구 금액 대신 청구 유형(최초 청구)을 표시합니다. 약국 문제에는 조제일·약국명·조제 구분을 표시합니다. 생년월일과 연락처는 마스킹된 가상 표기이며 서류 하단에 전시용임을 적었습니다.

## 진료비 세부산정내역 사진 (5.6)

- 참고 원본: [라이나생명 공개 진료비 세부산정내역 서식](https://m.lina.co.kr/upload/docs/claim/exam/medical_expense_detail.pdf)
- 게임 파일: `assets/detail-form-photo.png` (1536 × 1024)

원본 PDF 한 페이지에는 앞면 서식과 뒷면 작성 안내가 함께 있어, 앞면만 참고했습니다. 환자정보 띠, 12열 항목표, 급여의 일부본인부담·공단부담·전액본인부담 구분과 비급여 열을 살린 가로형 사진입니다. 긴 안내문은 게임용 짧은 안내로 바꾸고 실제 개인 데이터는 넣지 않았습니다.

단가·횟수·해당 금액은 같은 줄에 표시합니다. 중복 항목의 코드와 시행 시각도 함께 보이며, 한 원래 값에 선택 버튼 하나만 대응합니다. 5.7 신규 문제의 합계는 비급여 합계 또는 급여 본인부담 합계이며 각각 해당 부담 구분의 열 아래에 표시합니다. 총 진료비 열과 구분하며, 실제 수가나 보험금 지급 계산을 구현한 자료가 아닙니다. 기존 표의 자동 줄바꿈 대신 고정 사진 좌표에 글자와 클릭 영역을 배치합니다.

## 편집·확인 범위

위 병원 사진과 약국 예시 이미지를 직접 열어 확인한 뒤 이미지 편집으로 게임용 바탕을 만들었습니다. 결과 사진도 확인했습니다. 내려받은 원본 자료와 원본의 실제 개인정보는 배포 ZIP에 포함하지 않습니다. 사진을 편집했다는 사실과 원문 위치는 이 문서에 남겼으며, 원본 사진의 별도 재사용 허락을 확인했다는 의미는 아닙니다.

5.5에서는 사진을 HTML 이미지로 표시하고, 같은 크기의 영역에 일반 HTML 버튼을 겹쳐 놓습니다. 두 요소를 함께 확대·이동하므로 같은 좌표 계산을 공유합니다. 5.4의 SVG foreignObject 방식은 사용하지 않습니다. 사진 파일 자체는 5.4와 같습니다.

자동 검증은 원래 값·정답쌍 보존, 좌표 범위, 운영자·참가자 일치, 금액 관계, 이전 경기 복원, 오프라인 사진 포함 여부를 확인합니다. 실제 페이지 스크립트의 DOM 클릭 이벤트와 확대·이동 계산도 검사합니다. 이 환경에서는 실제 브라우저 실행이 제한되어 최종 화면의 픽셀 배치, 마우스 좌표 판정과 가독성은 실기 검증하지 못했습니다.

5.6의 청구서·세부내역 이미지도 일반 HTML 이미지와 버튼으로 표시합니다. 생성형 이미지 편집으로 인쇄·종이 질감을 만들고, 가상 값과 클릭 영역은 코드로 연결했습니다. 입력 이미지와 제작 지시는 FORM-PHOTO-PROMPTS.md에 기록했습니다. 원본 PDF와 원본 PNG는 배포본에 포함하지 않습니다.


## 5.7 — 비교값의 업무상 의미

근거로 확인한 자료:

- [국가법령정보센터, 진료비 계산서·영수증 별지 제6호서식](https://www.law.go.kr/LSW/flDownload.do?flSeq=171466439): 진료비 총액·공단부담 총액·환자부담 총액·이미 납부한 금액·납부할 금액·실제 납부액이 구분되어 있습니다.
- [라이나생명 공개 세부산정내역서 및 작성 안내](https://m.lina.co.kr/upload/docs/claim/exam/medical_expense_detail.pdf): 금액(단가), 횟수, 일수, 총액, 일부본인부담·공단부담·전액본인부담·비급여 열을 구분합니다.
- [삼성화재 질병·상해 청구 필요서류](https://www.samsungfire.com/da/manual/claim/M_P05_03_00_00.html): 진료비 영수증과 세부내역서를 구분하며 소득공제 확인용 진료비납입확인서는 대체 서류로 인정하지 않는다고 안내합니다.

이를 바탕으로 만든 게임 규칙입니다. 특정 보험사의 심사 규칙을 그대로 구현했다는 뜻은 아닙니다.

| 게임 상황 | 비교값 | 범위와 해석 |
|---|---|---|
| 병원 금액 대조 | 세부내역서 비급여 합계 ↔ 영수증 비급여 합계 | 동일 환자·기관·진료기간의 최종 정산. 조정·할인·환불이 없는 가상 사례. 불일치는 원본 확인 대상 |
| 약국 금액 입력 | 약제비 영수증 총 수납금액 ↔ 해당 영수증의 접수 입력 수납금액 | 환자·약국·조제일·영수증 번호 일치. 입력값 대조이며 보험금 지급액 산정이 아님 |
| 횟수 | 비급여 세부 항목의 산정 횟수 ↔ 시행 기록의 횟수 | 날짜·코드·항목·시각 일치. 단가 × 횟수 × 1일의 비급여 금액을 표시 |
| 환자·날짜 | 피보험자 ↔ 환자 성명, 진료일 ↔ 진료일 | 수령인·청구인과 환자, 발행일·접수일과 진료일을 같아야 하는 값으로 취급하지 않음 |
| 재접수 | 이번 영수증 번호 ↔ 기존 제출 영수증 번호 | 같은 기관·환자·진료 건. 재발급·보완 제출 확인이며 부정 청구 판정이 아님 |

신규 문제에서는 청구 금액과 의료비를 무조건 같아야 하는 값으로 비교하지 않습니다. 당시 진행 중인 이전 버전 경기는 문제와 선택 기록을 유지하며 새 게임부터 개선한 비교 기준을 사용합니다.

표로 만든 확인서·시행기록·접수내역도 사진과 같은 공통 크기 맞춤을 사용합니다. 제목, 모든 행, 서명, 꼬리말을 포함한 전체 문서 크기를 측정하여 한 장으로 맞춥니다. 실제 브라우저 시각 검증의 제한은 위와 같습니다.
