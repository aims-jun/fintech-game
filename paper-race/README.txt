있습니다. 영수증 사진, 글꼴과 게임 코드가 들어 있어 별도 설치나 인터넷이 필요 없습니다.
두 창을 연결해 행사에서 운영할 때는 아래 실행기를 사용하세요.

행사 운영 시작하기
1. ZIP 파일을 모두 압축 해제합니다. 폴더 안의 파일을 함께 두세요.
2. Mac: start.command를 더블클릭합니다.
   Windows: start.bat를 더블클릭합니다.
   Python 3가 필요하며 추가 패키지나 인터넷 연결은 필요하지 않습니다.
3. 자동으로 열린 운영자 화면에서 관객 화면을 새 창으로 여세요.
4. 관객 창을 큰 모니터로 옮기고 F를 눌러 전체 화면으로 만드세요.
   운영자 창은 노트북 화면에 둡니다. 두 창은 같은 브라우저에서 여세요.
5. 게임이 진행되는 동안 실행된 터미널 창은 열어 두세요.

Mac에서 더블클릭 실행이 막힐 때
터미널에서 "cd "를 입력한 뒤 압축을 푼 폴더를 터미널로 끌어 놓고 Enter를
누르세요. 이어서 아래 명령을 입력하면 됩니다.

python3 server.py

게임 진행
운영자 화면에서 참가자 닉네임과 난이도를 정하고 게임을 시작하세요.
참가자는 3개의 사건에서 문서 내용을 비교하고 맞는 짝을 찾아 선택합니다.
AI 상대의 진행은 체험용으로 연출된 시뮬레이션입니다. 실제 AI 제품의 성능을
측정하거나 비교하는 벤치마크가 아닙니다.

문제와 서류
6가지 유형, 21개 상황을 준비했습니다.
- 날짜: 청구서에 쓴 진료일과 영수증의 진료일 비교
- 이름: 청구서의 피보험자와 확인서·약제비 영수증의 환자 성명 비교
- 금액: 같은 진료 건의 세부내역서 비급여 합계와 영수증 비급여 합계 비교
  약국은 원본 영수증 수납금액과 접수할 때 입력한 수납금액 비교
- 횟수: 같은 날짜·코드·시각의 비급여 항목 산정 횟수와 시행 기록 비교
- 중복 항목: 같은 코드·항목·시각의 두 금액을 고르고 시행 기록과 대조
- 재접수: 같은 기관·환자·진료 건의 영수증 번호를 기존 접수 이력과 대조

한 게임은 쉬운 비교 → 금액·횟수 비교 → 중복 확인의 3문제로 구성됩니다.
새 경기에는 병원 영수증과 약국 영수증이 한 번 이상 나오며, 새 게임마다
이름·날짜·금액 등도 달라집니다. 같은 게임 안에서는 새로고침해도 문제가 바뀌지 않고, 운영자와
관객 화면에 같은 자료가 보입니다. 모든 21개 문제를 연속해서 푸는 모드는
아니며, 아래 「문제 보기」에서 전체 문제를 살펴볼 수 있습니다.

한국 병원·약국 영수증 사진
국내에서 실제 발급된 영수증 사진을 참고해 게임용 사진으로 편집했습니다.
원본의 이름, 날짜, 기관명, 등록번호, 금액은 지웠으며 게임이 만드는 가상
정보를 해당 칸에 표시합니다. 서류 아래에 전시용 가상 자료임을 적었습니다.

- 병원: 실제 외래 진료비 계산서·영수증의 촘촘한 표, 급여·비급여 열,
  항목별 금액, 오른쪽 수납 내역을 사용합니다.
- 약국: 약 봉투에 인쇄된 약제비 계산서·영수증 부분을 따로 편집했습니다.
  녹색 인쇄선, 조제일, 투약일수, 본인부담금과 총 수납금액이 들어갑니다.
- 사진 속 이름·날짜·금액도 직접 선택할 수 있습니다. 정답 칸만 굵게 하거나
  별도 호버 효과로 표시하지 않습니다.
- 약국 문제 3개: 환자 이름 비교, 영수증 수납금 입력 오류, 재접수 확인.
  금액 문제는 청구서 대신 「약제비 서류 입력 내역」과 원본을 비교합니다.
  같은 영수증 번호·환자·약국·조제일을 표시하며 보험금 지급액을 비교하지 않습니다.

사진의 서식과 글자는 화면 크기에 맞춰 함께 확대·축소됩니다. 사진과 클릭
영역이 같은 좌표를 사용하며, 운영자 화면에도 같은 자료를 보여줍니다.
영수증 오른쪽 위 「확대」를 누르면 2.5배로 볼 수 있습니다. 확대한 상태에서도
값을 눌러 선택할 수 있고, 빈 곳을 드래그하거나 휠·방향키로 영수증 안을
이동할 수 있습니다. 「전체 보기」 또는 Esc를 누르면 원래 크기로 돌아옵니다.
원문 링크와 사진 편집 범위는 FORM-REFERENCES.md에 적었습니다. 운영자
「문제 보기」에서도 각 영수증의 출처를 열 수 있습니다.

청구서와 진료비 세부산정내역도 실제 공개 서식을 참고한 사진으로 표시합니다.
청구서는 인적사항·진료 및 청구 내용·수령 계좌·서명 구역을 갖추고, 세부내역은
환자정보와 급여·비급여 12열 표를 사용합니다. 가로형 세부내역에는 화면 폭을
조금 더 배분했습니다. 글자와 선택 칸이 표와 함께 확대되며 따로 줄바꿈되지 않습니다.
이 서류들도 오른쪽 위 「확대」로 크게 보고 값을 선택할 수 있습니다.
확인서·시행기록·접수내역은 제목부터 마지막 행·서명·꼬리말까지 한 장으로
묶어 전체 크기를 재고 표시 영역에 맞춥니다. 창 크기나 글꼴 로딩으로 문서
크기가 바뀌면 다시 맞춥니다. 내용을 잘라내거나 표 내부를 스크롤하지 않습니다.
사진 위의 글자도 사진과 같은 비율로 줄어듭니다. 작게 보이면 「확대」를 사용하세요.

비교 기준
금액 문제는 동일 환자·기관·진료기간의 최종 정산 자료라는 설정입니다.
합계 조정·할인·환불이 없는 가상 사례이며 비급여끼리 비교합니다.
진료비 총액, 공단부담금, 환자부담액, 이번 납부액은 서로 다른 항목입니다.
세부내역서의 비급여 합계는 비급여 열 아래, 급여 본인부담 합계는 본인부담 열
아래에 놓습니다. 환자부담 합계를 전체 진료비 총액 칸에 넣지 않습니다.
횟수 문제의 단가는 비급여 항목의 단가이며 일수 1일 × 횟수 × 단가로 계산합니다.
청구서에는 임의의 청구 금액 대신 청구 유형을 표시합니다.
영수증 번호가 같다는 이유만으로 잘못된 청구로 판정하지 않습니다.
재발급·보완 제출인지, 반복 시행 기록이 있는지 확인하는 상황입니다.
게임용 공단부담액은 실제 의료수가나 본인부담률을 적용한 값이 아닙니다.
금액은 원 단위이며 표 안의 숫자에서는 '원'을 생략합니다.

운영 전 문제 살펴보기
운영자 화면 오른쪽 위 「문제 보기」를 누르세요. 21개 상황을 골라 볼 수 있고,
「다른 자료」는 같은 상황의 이름·날짜·금액 등을 바꿔 보여줍니다.
서류의 값을 직접 눌러 두 곳을 선택해보세요. 맞으면 두 값과 설명이 표시되고,
틀리면 바로 다시 선택할 수 있습니다. 「정답 보기」로 확인하는 것도 가능합니다.
이 화면은 실제 경기나 점수를 바꾸지 않으며, 경기 중에는 열리지 않습니다.

이전 버전에서 진행 중이던 경기는 원래 문제 그대로 이어집니다.
다음 새 게임부터 새 문제 묶음을 사용합니다. 기존 점수 저장 방식은 같습니다.

관객 화면 단축키

Space   일시정지 / 계속
M       음소거 전환

점수와 닉네임
닉네임과 점수는 해당 브라우저의 로컬 저장소에만 보관됩니다.
운영자 화면 위쪽의 「기록 · CSV」에서 난이도별 기록을 확인하고
CSV 파일로 내보낼 수 있습니다. 최근 200회의 결과를 보관합니다.
행사 전후로 CSV를 저장해 두세요. 브라우저 데이터를 지우거나 시크릿 창을
닫으면 기록이 사라질 수 있습니다.

같은 브라우저 + 같은 주소(포트 포함)를 사용해야 이전 기록이 보입니다.
관객 창과 운영자 창도 같은 주소의 서버를 사용해야 서로 연결됩니다.
예: http://127.0.0.1:8765/index.html 과 같은 포트의 operator.html

실행 및 이전 화면 문제
실행기는 8765번 포트를 먼저 사용하고, 사용 중이면 8799번까지 빈 포트를
자동으로 찾습니다. 다른 프로그램이나 예전에 켜 둔 서버를 종료하지 않습니다.
같은 폴더의 v5 서버가 이미 실행 중이면 기존 주소를 다시 엽니다.
새 게임 파일은 매번 최신 내용을 보내도록 설정되어 있습니다.
예전 즐겨찾기 대신 이번 실행기가 표시한 주소를 사용하고 화면 아래쪽의 ARENA 5.8 표시를
확인하세요. 포트가 달라져 예전 점수가 보이지 않으면 이전 주소에서 CSV를
내보내세요. 점수는 포트 사이에 자동으로 이동하지 않습니다.

브라우저가 자동으로 열리지 않으면 터미널의 "운영자 화면" 주소를 복사하여
열면 됩니다. 두 창을 연결할 때는 파일 직접 열기 대신 실행기를 사용하세요.
모든 후보 포트가 사용 중이면 다음처럼 시작 포트를 바꿀 수 있습니다.

python3 server.py --port 8900

터미널에서 Ctrl+C를 누릅니다. 새 서버는 이 컴퓨터 내부(127.0.0.1)에서만
열립니다. 이 구성은 한 컴퓨터의 두 창을 위한 것이며 다른 기기의 휴대전화로
접속하는 방식은 지원하지 않습니다.

게임 규칙
- 연습은 시간 제한이 없습니다. 본 게임은 3초 카운트다운 뒤 시작합니다.
- 여유롭게 45초 / 보통 30초 / 빠르게 20초. 보이는 시간이 AI 완료 시점입니다.
- 이름·날짜, 금액·횟수, 중복 관련 문제를 차례로 찾습니다. 한 문제에 두 곳을 누르세요.
- 이름이나 숫자가 적힌 칸을 누르면 선택할 수 있습니다.
- 이미 선택한 항목을 다시 누르면 선택을 취소합니다.
- 정답 +1,000점, 오답 -100점, 힌트 -150점. 점수는 0 아래로 표시하지
  않지만, 초반에 사용한 힌트와 오답도 다음 정답 점수에 반영됩니다.
- 완주하면 남은 시간 0.1초당 2점의 보너스를 받습니다.
- 정답 확인 1.8초 동안은 참가자와 AI의 시간이 함께 멈춥니다.
- 단축키 Space는 빈 곳에 포커스가 있을 때 시작/정지로 작동합니다.
  버튼에 포커스가 있으면 Space/Enter로 해당 버튼을 누릅니다.
- 소리는 처음 한 번 클릭한 뒤, 현재 조작 중인 창에서 재생됩니다.

검증 범위
엔진의 시간/승패/점수/공유 상태, 21개 가상 상황의 계산·시각·정답쌍,
두 실행 컨텍스트의 문제 일치, 표 구조와 사진의 선택 좌표, HTML 이스케이프, 이전 경기 복원,
실행기의 포트 충돌과 캐시 응답, 패키지 파일 및 JavaScript 구문을 자동 점검했습니다.
5.7에서는 같은 의미의 비교값과 합계 열 배치, 문서 전체 크기 맞춤을 추가로
검사했습니다. 청구서·세부내역서·영수증을 대상으로 실제 app.js와 operator.js의

일시정지와 문제 보기의 동작도 확인했습니다. 확대·이동·리사이즈의 좌표 계산을 검사했습니다.
